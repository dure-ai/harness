## A. 포지셔닝과 10/29에 말할 것

### A.1 포지셔닝 문장

> **T5 하네스는 새 메모리 벤치마크가 아니라, 팀이 함께 쓰는 코딩 에이전트 메모리 엔진을 넣거나 바꾸기 전에 돌리는 결정적·저비용 회귀 게이트(v0.1)다. 같은 입력과 같은 규칙 에이전트로 틀린 근거 채택(M1)·맞는 근거 활용(M2)·범위 누출(M3 = 0)을 전부 저장 기준선과 비교한다. 규칙 에이전트가 실제 LLM 에이전트를 대신할 수 있는지는 아직 검증하지 않았고, 12월 교정 연구로 검증한다.**

근거: t4 §5.1 [판단]. "벤치마크"로 나가면 DreamBench-SWE(엄밀성), VibeMemBench(외적 타당도), MemRiskBench(위험 분류), GovMem(독립성)과 정면 비교되고 지금은 진다. "출시 전 게이트"라는 틀에서는 우리 강점(결정적, 기준선 실행 0.16초, 같은 입력, 누출 하드 게이트, 팀 범위, 자가 검증)이 필요한 성질이 되고, 약점(규칙 에이전트, 소규모)은 "게이트의 민감도를 교정해야 한다"는 후속 과제가 된다.

| 항목 | 표기 예 | 이유 |
|---|---|---|
| 문항 수 n | `M1 0.20 (n=30)` | 판정이 문항 몇 개에 좌우되는지 |
| 시나리오(군집) 수 | `30문항 / 18시나리오` | 문항은 독립이 아니다 |

| 기준선 비교값 | `all_store M1 1.00 / oracle 0.00, 엔진 절대 M1 0.20` | 상대 판정선이 사실상 절대 0.5로 굳는 것을 드러냄 |
| 누출 | `M3 0/40 문항 (95% 상한 0.088)` | 0건 ≠ 위험 0 |
| M1 상한 띠 | `노출률 0.35` | 규칙 에이전트 가정의 민감도 |
| 채점 경로 | `markers 판정 4%, 출처 없는 결과 2%` | 출처 비대칭 |
| 엔진 조건 | `virtual_clock ✗ → 시간 계열 비교 불가`, 버전·이미지·모델 | 공정성 조건 |
| 반복 | `3회, 구간은 1회차 기준, 뒤집힘률 0.12` | 비결정성 |
| 오류 | `오류 시나리오 1(인프라, 1회 재실행 후 정상)` | 인프라 노이즈와 엔진 결함 구분 |
| 세트·설정 | `dev 승인 24개(전부 author: llm), 계열 8개, 세트 해시 …, 설정 v0.3, 태그 prereg-v0.3` | 재현성, 작성 편향 공개 |
